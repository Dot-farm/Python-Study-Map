# Python Study Map

This repository collects three Python learning documents and a standalone HTML dashboard for comparing them. The materials progress from beginner foundations to a focused course on functions and modules; the dashboard summarizes their section coverage and teaching/code-example metrics.

## Learning materials

- [`master-beginner-python.md`](master-beginner-python.md) — a beginner-to-intermediate curriculum covering core syntax, data types, control flow, collections, functions, exceptions, file I/O, modules, OOP, practice projects, and a learning roadmap.
- [`beginner-python-programming.md`](beginner-python-programming.md) — a detailed foundational reference with explanations and examples spanning Python basics through SQLite and Tkinter.
- [`GDP - Functions and Modules.md`](GDP%20-%20Functions%20and%20Modules.md) — a course focused on functions, scope, function-as-value concepts, type hints, testing, modules/packages, and a shop-inventory CLI project.

## Study map

Open [`Python Study Map.html`](Python%20Study%20Map.html) in a browser to compare all three documents or select one. The dashboard includes section-level metrics, charts, a topic-coverage matrix, and a searchable, sortable section table. Its summary data is embedded in the HTML file. Chart.js and IBM Plex fonts are loaded from external CDNs, so an internet connection is needed for those assets (particularly the charts).

## Using this repository

There is no package manifest, build script, or application setup to run. Read the Markdown files in a Markdown viewer/editor, or open the HTML file directly in a browser. No project-level automated test suite or test command is present; exercises and example checks are part of the teaching material.
